# وضعیت فعلی و طرح آزمایش‌های مقایسه (برای استاد)

## ۱. وضعیت فعلی سه مورد

| | پروژه ما (CodeQAPass) | RepoReaper | CodeQA |
|---|---|---|---|
| ماهیت | سامانهٔ RAG برای فهم مخزن Python، فارسی/انگلیسی | agent تحلیل مخزن و چت RAG (متن‌باز، MIT) | دیتاست پرسش‌وپاسخ سطح snippet (EMNLP 2021) |
| ورودی | کل مخزن | آدرس GitHub، فایل‌ها با JIT بارگذاری می‌شوند | یک تکه کد + یک پرسش |
| بازیابی | lexical، semantic، hybrid (RRF بدون وزن، k=60) | BM25 + برداری، RRF وزن‌دار (۱٫۰/۰٫۳)، بازنویسی پرسش با LLM | ندارد |
| ارجاع | قطعی از metadata: مسیر، سمبل، بازهٔ خط | متن مدل؛ context فقط مسیر فایل دارد | ندارد |
| شواهد ناکافی | بازگشت صریح بدون فراخوانی مدل | تلاش برای «بهترین پاسخ» | ندارد |
| معیارهای ارزیابی | Hit@k، MRR، امتیاز کیفی، دقت citation، بازبینی دو LLM + داور خودکار | چارچوب دارد (Hit rate، Recall@k، Precision@k، MRR، داور LLM)، **عدد منتشر نشده** | BLEU، ROUGE-L، METEOR، EM، F1؛ انسانی (روانی و درستی ۱ تا ۳) |
| داده | ۳ مخزن خودمان + ۹۶ پرسش SWE-QA | ۶۳ پرسش دربارهٔ مخزن خودش (۳۹ چینی، ۲۴ انگلیسی) | Python: ۵۶٬۰۸۵/۷٬۰۰۰/۷٬۰۰۰؛ Java: ۹۵٬۷۷۸/۱۲٬۰۰۰/۱۲٬۰۰۰ |
| نتیجهٔ منتشرشده | در مقاله | ندارد | Python test: CodeBERT F1=31.56، ROUGE-L=30.28، EM=4.93 |

(عددهای CodeQA از نسخهٔ HTML مقاله از طریق خلاصه‌ساز استخراج شده‌اند و قبل از استفاده باید با مقاله تطبیق داده شوند.)

## ۲. آنچه تاکنون روی SWE-QA انجام و اندازه‌گیری شده

- ۹۶ پرسش (۴۸ Flask، ۴۸ Requests)، سه بازو: بدون بازیابی (A0)، RAG با citation قطعی (A1)، citation انتخابی مدل (A2).
- داور خودکار (Gemini 2.5 Flash): تفاوت A1 و A0 معنادار نیست (میانگین +۰٫۴۴ از ۲۰، بازه شامل صفر).
- بازبینی کور دو LLM روی ۳۰ پرسش: A1 در groundedness (+۲٫۹۵ از ۱۰) و correctness (+۲٫۰۳) بهتر.
- citation: A1 ساختاری ۱۰۰٪ معتبر (به‌حکم ساخت) ولی دقت معنایی ۶۶–۷۱٪؛ A2 دقت ۸۷–۹۹٪.
- محدودیت: ۳۰ نمونه، ارزیاب انسانی نیست، توافق ارزیاب‌ها متوسط.

## ۳. چرا مقایسهٔ مستقیم اعداد منتشرشده معتبر نیست
- CodeQA سطح snippet است و بازیابی ندارد؛ baselineهای آن مدل‌های fine-tune شده‌اند.
- RepoReaper عدد منتشر نکرده است.
- بنچمارک SWE-QA و داور رسمی آن (GPT-5) با تنظیم ما یکی نیست.

## ۵. هشدارها
- ارزیابی انسانی و ارزیاب‌های LLM را جدا گزارش کنیم؛ فعلاً فقط LLM داریم.
- مقایسه با CodeQA و مقایسه با نتایج منتشرشده «غیرمستقیم» است و باید همین‌طور نوشته شود.
- RepoReaper را فقط با اجرای خودمان و تنظیم عادلانه (همان مدل/embedding/داده) می‌توان کمی مقایسه کرد.
- مقایسهٔ ویژگی‌های کیفی (جدول بخش ۱) همین حالا قابل نوشتن است.
- مهلت کنفرانس IKT ۲ اکتبر ۲۰۲۶ است؛ اگر هدف ژورنال است، این طرح به آن می‌خورد.
